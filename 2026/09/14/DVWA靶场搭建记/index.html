DVWA靶场搭建记

为什么要搭 DVWA

在学习网络安全的过程中，需要一个合法的练习环境来熟悉 Web 漏洞的原理和利用方式。DVWA（Damn Vulnerable Web Application）是一个用 PHP/MySQL 编写的、包含常见 Web 漏洞的靶场，是入门 Web 安全的经典练习平台。

搭建环境

  • 操作系统：Kali Linux 虚拟机
  • Web 服务器：Apache2
  • 数据库：MariaDB
  • 编程语言：PHP

搭建过程

1. 安装 Web 环境

在 Kali 终端中执行：

sudo systemctl start apache2
sudo systemctl start mariadb

cd ~/桌面
unzip DVWA-master.zip
mv DVWA-master /var/www/html/dvwa


### 4. 配置数据库和权限

按照 DVWA 文档要求，配置数据库连接信息并修改目录权限，确保 PHP 可以写入配置文件。

### 5. 初始化安装

浏览器访问 `http://127.0.0.1/dvwa/setup.php`，点击 **Create / Reset Database**，初始化完成后用默认账号登录：

- 用户名：admin
- 密码：password
