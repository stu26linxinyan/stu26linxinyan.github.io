为什么要搭博客

作为大一新生，一直想拥有一个属于自己的个人博客。经过了解，选择了 GitHub + Hexo 的方案，免费、稳定，还能顺便学习 Git 命令行操作。

搭建过程

1. 安装 Node.js

去 Node.js 官网下载 LTS 版本，一路下一步安装即可。安装完在命令行输入 node -v 和 npm -v 验证是否成功。

2. 安装 Git

通过 winget install --id Git.Git -e --source winget 一键安装 Git。

3. 安装 Hexo

npm install -g hexo-cli
hexo init my-blog
cd my-blog
npm install
hexo s
